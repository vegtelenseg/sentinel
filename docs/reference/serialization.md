# Serialization

[← Documentation home](/)

| Export | Purpose |
|---|---|
| `exportRules` / `exportRulesToJson` | Rules → JSON document |
| `importRules` / `importRulesFromJson` | JSON → rules |
| `ConditionRegistry` | Name → condition function |

`JsonPolicyDocument` version is `1`. Conditions in JSON are string names resolved at import.

See [JSON policy serialization](../guides/json-serialization.md).
